サンドボックス（`~/claude-sandbox/`）の成果物を Copilot に送信してクロスレビューを実行します。

**プランモード中は実行不可。** Bash実行によりプランモードが自動解除されるため、プラン承認後に実行すること。

## 使用方法

```
/cross-review [ファイル名]
```

### 引数
- `<ファイル名>`（任意）: `~/claude-sandbox/` 配下のレビュー対象ファイル名
- 引数なしの場合: 現在のコード差分からレビュー用ファイルを自動生成してクロスレビューを実行する

### 引数: $ARGUMENTS
