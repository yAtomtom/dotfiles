---
description: "プルリクエストを作成する"
---

プッシュ済みの変更をもとにプルリクエストを作成します。
勝手にコミットやプッシュは行いません。

## 使用方法

```
/pr [オプション]
```

### オプション
- `draft`: Draft PRとして作成
- 引数なし: 通常のPRを作成

## エラー時の対処

以下の問題を検出した場合はユーザーに報告し、勝手にコミットやプッシュは行わない:

- コミットされていない変更がある場合
- ブランチがプッシュされていない場合
- GitHub CLIの認証が必要な場合
- リモートリポジトリへのアクセス権限がない場合
- ベースブランチとのコンフリクトがある場合
