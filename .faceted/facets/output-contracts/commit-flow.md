## 実行フロー

1. `git diff --cached` でステージング済みの変更内容を把握
2. `git status` でステージング外の変更も含めた全体状態を確認
3. テンプレートを探索し、コミットメッセージを作成
4. `git commit -m "コミットメッセージ"` を実行
5. コミット後に `git log --oneline -1` で確認
6. `git status` を実行し、出力をレポートに含める

## 禁止事項

- ステージング内容の変更（追加・削除）
- 大量の無関係な変更を1つのコミットに含める
- .envファイルや秘密鍵などの機密情報のコミット
