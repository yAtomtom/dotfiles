## 事前確認

1. リモートへのpush状態を確認（pushされていなければユーザーに依頼して終了）
2. 現在のブランチ状態を確認
3. ベースブランチ（main/master/develop等）を特定してfetch

## PR作成フロー

1. デフォルトブランチとの差分とコミットメッセージを確認
2. PRの本文を提案
   - `.claude/skills/pr/SKILL.md` の指示に従う
   - `.github/PULL_REQUEST_TEMPLATE.md` が存在すればフォーマットとして使用
   - テンプレートが存在しない場合はユーザーに確認
3. **必ずユーザーに提案内容を提示し、許可を得る**
4. 許可が得られれば `gh pr create` でPR作成
5. PR作成後、PRへのリンクを表示

## 禁止事項

- リモートブランチの作成
- git push操作
- pushされていない状態でのPR作成
- ユーザーの許可なしでのPR作成
